What Should We Fix First

Every part of the service, ranked by the score points we would win back by fixing it. The last column is the one to act on.
How to read this

Anyone who answered "Not applicable" is left out completely. If you never used the courier service, your opinion of it is not counted for us or against us.

Which Site Has Which Problem

Each cell: of the people at that site who used that service, the share who were not satisfied. Darker means worse; the worst services are at the top.
How to read this

The numbers are not meant to add up to 100% in any direction. Every cell has its own separate group of people, because different customers use different services. At Lekki, for example, nearly everyone has a view on urgent results, but only the customers who had a sample collected by courier can rate the courier. The small figure inside each cell is that cell's own base; the count under each site name is the site total, for context only.

A blank cell means fewer than 5 people at that site used that service, which is too few to put a number on.

What Customers Actually Wrote

Both the complaint box and the suggestions box are read; non-answers ("Nil", "N/A", a bare email address) are filtered out.
How to read this

Most written feedback actually arrives through the suggestions box, not the complaint box, so both are treated as feedback.

Themes come from keyword matching, and one comment can carry more than one theme, so theme mentions add up to more than the comment count. The original comments are always shown unedited, so every theme count can be checked against what customers actually wrote.

Downloads

For anyone who wants to check this dashboard against the source, or do their own analysis in Excel or Power BI.
  • Original survey responses (Excel)
    Every response exactly as exported from Microsoft Forms: same rows, same columns, same values. The contact-detail columns (names, emails, phone numbers) are blanked for privacy; everything else is untouched.
  • Original survey responses (CSV)
    The same data as the Excel file, for tools that prefer CSV.
  • Cleaned dataset (CSV)
    One row per response after cleaning: standardised site names, region, NPS band, themes. This is exactly what the dashboard's own numbers are computed from.
  • Cleaned dataset (JSON)
    The same cleaned data, for developers and Power BI.

The fully unredacted export, with customer contact details, never leaves the computer that runs the daily refresh. Staff doing call-backs use private/service-recovery.csv on that machine, matched by case number. In this demo every response, name and comment is invented.
